# (internal) Compute and plot Relative Log Expression for a chosen data in as RiboClass

(internal) Compute and plot Relative Log Expression for a chosen data in
as RiboClass

## Usage

``` r
.plot_rlc(mat = NULL, show_outlier, col_to_plot)
```

## Arguments

- mat:

  matrix

- show_outlier:

  Show outliers on the plot ?

- col_to_plot:

  data column to plot values from

## Value

a ggplot object
