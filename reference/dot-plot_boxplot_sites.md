# Internal function for boxplot_cscore

Internal function for boxplot_cscore

## Usage

``` r
.plot_boxplot_sites(matrix, values_to_plot, outlier, sort_by, horizontal)
```

## Arguments

- matrix:

  Sites x Samples C-score/count matrix (output of extract_data()).

- values_to_plot:

  Value to display in plot.

- outlier:

  Show boxplot outlier values.

- horizontal:

  Show boxplot horizontally.

## Value

A ggplot object.
