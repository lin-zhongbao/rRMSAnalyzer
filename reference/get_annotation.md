# Get annotation of a RiboClass

Get annotation of a RiboClass

## Usage

``` r
get_annotation(ribo)
```

## Arguments

- ribo:

  A RiboClass

## Value

A dataframe with the rna name, the position on the rna and the annotated
site.

ribo_toy <- annotate_site(ribo_toy,human_methylated)
get_annotation(ribo_toy)
