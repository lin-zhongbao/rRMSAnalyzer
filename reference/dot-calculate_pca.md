# Compute PCA from a c-score matrix

Compute PCA from a c-score matrix

## Usage

``` r
.calculate_pca(cscore.matrix = NULL)
```

## Arguments

- cscore.matrix:

  matrix of c-score extracted from a RiboClass with '
  [`extract_data`](https://ribosomecrcl.github.io/rRMSAnalyzer/reference/extract_data.md)

## Value

dudi.pca object
