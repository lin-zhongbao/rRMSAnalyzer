# Known and suspected 2'Ome positions in human rRNAs

A dataset containing 129 2'Ome positions with associated data

## Usage

``` r
data(human_both_methylated_and_suspected)
```

## Format

A data frame with 129 rows and 10 variables:

- Position:

  nucleotide position on rRNA

- rRNA:

  rRNA where this methylation is found

- Nomenclature:

  name given to this modification

- NR_046235.Numbering:

  Position on

- Sequence:

  nucleotides sequence surround position

- SNORD:

  ID of associated snoRNA

- Mode.of.coding:

  how the SNORD is coded

- SNORD.host.gene:

  SNORD's host gene

- Ensembl:

  SNORD's Ensembl reference

- Nucleotide:

  the nucleotide present at the position (A,T,G or C)
