# Generate the col argument for ComplexHeatmap::HeatmapAnnotation

Generate the col argument for ComplexHeatmap::HeatmapAnnotation

## Usage

``` r
generate_palette(metadata, cols_to_use)
```

## Arguments

- metadata:

  A data.frame containing sample metadata

- cols_to_use:

  The name of the column to generate colors for

## Value

A named vector of colors
