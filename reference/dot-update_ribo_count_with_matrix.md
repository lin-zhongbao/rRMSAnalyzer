# Update count values inside a RiboClass with a matrix of values

Update count values inside a RiboClass with a matrix of values

## Usage

``` r
.update_ribo_count_with_matrix(ribo, update_matrix)
```

## Arguments

- ribo:

  a RiboClass object

- update_matrix:

  a position x sample matrix containing the new values

## Value

a RiboClass with updated values
